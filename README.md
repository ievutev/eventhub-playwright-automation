# EventHub E2E Test Automation Project

This repository contains an end-to-end (E2E) test automation framework built for the [EventHub platform](https://eventhub.rahulshettyacademy.com/) using Playwright and TypeScript. 

Designed as a portfolio project to demonstrate QA automation best practices, the framework focuses on reliable UI testing, clean architecture, and scalability.

---

## Tech Stack

* **Language:** TypeScript
* **Test Framework:** Playwright Test
* **Design Pattern:** Page Object Model (POM)
* **Target Application:** EventHub (Rahul Shetty Academy)

---

## Testing Scope

The automation suite covers key user stories and workflows across the platform:
* **Home Page:** Navigation, featured events, and quick links.
* **Events & Booking:** Keyword search, category/city filtering, form validations, and booking confirmation.
* **My Bookings:** Viewing booking details and cancelling reservations.
* **Admin Section:** Event creation validations, booking management, and status filtering.
